# 通用文档风格（Markdown / YAML / JSON）

## 1. YAML

- 缩进统一 **2 空格**，**禁止 tab**（YAML 中 tab 非法）

## 2. JSON

- 缩进统一 **2 空格**，文件以一个空行结尾

## 3. Markdown

- 代码块必须标注语言（`bash` / `cpp` / `python` 等）
- 文件以一个空行结尾；列表、表格前后各留一空行

## 4. .editorconfig

- 仓库根目录放 `.editorconfig` 可一次性落实以上缩进规则，模板见 skill `assets/.editorconfig`

> 说明与模板见 skill：[`docs-style.md`](https://github.com/unnc-aim/aim-common-agentic-skills/blob/main/.agent/skills/aim-common-rules/references/docs-style.md)。
